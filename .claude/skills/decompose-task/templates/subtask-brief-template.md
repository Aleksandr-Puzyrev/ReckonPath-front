## Definition of Done

* Флоу работает по ТЗ, включая состояния: загрузка, пусто, ошибка, офлайн; обе темы; RU и EN.
* Обязательные тесты среза написаны и зелёные.
* `npx expo lint`, `npx tsc --noEmit`, `npm test` без ошибок.
* Изменены только файлы из «Файлы во владении».
* Ответ оркестратору: список файлов, принятые допущения, найденные пробелы ТЗ и проблемы вне границ (не исправлять, только сообщить).
