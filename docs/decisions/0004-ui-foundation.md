## Consequences

* Expo Go no longer runs the app; development builds are required.
* `.claude/rules/13-rule-ui-unistyles-tokens.md`: themes follow the system (decision #2); `bg.glass` is a project token outside spec Part 3.
* Where spec sizes and design sizes differ, the developer's preference is the design; the agent still asks per case (decision #8).
