2Reckon Path v2 — выбрано 1a
Поле везде плоское (1a); баннер на главной — наклонённое поле с элементами. Доработана светлая тема, логотип-надпись, иконки ◆ и ●, новый список уровней. Знак заменён на новый, название RECKON PATH набрано шрифтом. Добавлены вход через VK ID и по логину с паролем, а также регистрация. Экраны разбиты на фреймы 01–06 в порядке пути игрока. Панель Tweaks: тема, RU/EN, iOS/Android. Прошлая версия лежит в файле Reckon Path.dc.html. Новое: 07 Арена, 08 Витрина, 09 Профиль; анимации — плавающие элементы баннера, блики на кнопках, появление карточек, радар поиска. Пакет 1 (механика, бомбы, итоги) — в файле Reckon Path Mechanics.
